# Learning Management System (LMS) Cross-Platform App

This repository contains the source code for a comprehensive, cross-platform Learning Management System (LMS) application developed for our client. 

## Developed By
**JAAN Network (Pvt) Ltd.**

## Tech Stack
* **Framework:** Flutter (Android, iOS, Web)
* **Backend:** Firebase (Authentication, Firestore, Cloud Messaging)
* **Architecture:** Feature-first Clean Architecture

## Key Features
* Cross-Platform support (Android, iOS, Web)
* User Authentication (Admin, Student)
* Course Subscriptions & Content Management
* Secure Online Payments & Coupons (PayHere)
* Live Classes (Zoom Integration)
* Online Assessments, Submissions & Automated Grading
* System Broadcasts & Real-time Notifications
* Dynamic Certificate Generation
